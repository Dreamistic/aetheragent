# Aether Flutter Client

This directory contains the Flutter client source.

Flutter 3.44.4 is installed at `C:\src\flutter`. Open a new PowerShell window so user PATH is refreshed, then run:

```powershell
cd path\to\Aether\client
flutter pub get
flutter run -d windows
```

The Windows platform folders have been generated. If plugin builds require symlink support, enable Windows Developer Mode with `start ms-settings:developers`.
